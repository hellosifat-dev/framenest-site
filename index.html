Features

Everything a creator platform needs, wired end to end.

Not a mock-up. Accounts, uploads, likes, subscriptions, verification, wallet and moderation all run through one API and one database.

Real video uploads

Upload with a progress bar and thumbnail, save as draft, send for review, then publish. Edit or delete at any time.

Likes, comments, subscribe

Viewers follow creators, like and comment. Views are counted once, so refreshing does not inflate numbers.

Premium content

"Subscribers only" videos: the file URL is only given to subscribers, the owner and admins.

Creator verification

NID or passport plus a selfie. Documents are never public and only an admin can view them through an authenticated request.

Wallet and withdrawals

Balance, withdraw requests with minimum and monthly limits, and admin "Paid" or "Reject" with automatic refund.

Studio analytics

Real views from the view log for the last 7 days, earnings and top videos, all in the creator studio.

Notifications

Subscribe, comment, approval, rejection, verification and withdrawal events each create a real notification.

Admin moderation

Stats, verification review, withdrawals, reports, content moderation, user ban and role changes, and an audit log.

Bangla first, light and dark

The interface speaks Bangla where it matters, with English labels, and follows light, dark or system theme.

How it works

From upload to audience.

A video moves through clear states, and nothing is public until an admin approves it.

draftpending reviewpublishedor rejected, with a notification

Sign up

JWT sessions with bcrypt passwords. Every request re-checks the user, so a ban works instantly.

Upload

The file type is taken from the real MIME type, not the filename, and stored with a thumbnail.

Review

Admins approve or reject. The creator gets a notification either way.

Watch and earn

Views, likes and subscriptions feed the studio. Premium videos stay behind the subscription.

Tech and security

Small stack, careful defaults.

The whole API lives in one Express server backed by SQLite. The frontend is plain HTML, CSS and JavaScript served by the same server, so there is nothing to build.

  • All user text is HTML-escaped against XSS
  • Separate rate limits for login and signup, helmet and a CORS allow-list
  • Payment details and stream keys never leave the API
  • JWT secret and first admin created automatically on first run
